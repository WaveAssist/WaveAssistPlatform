WaveAgent — how people use it hosted · zero-install

The WaveAssist MCP server is hosted. A user adds one URL with their WaveAssist UID in a header — exactly like a Slack or GitHub MCP — then describes the agent they want. The host's coding agent builds, live-tests, and deploys it on a schedule.

No uv, no Python, no install. On hosts with native remote-MCP it's literally just the URL; on the rest, one npx mcp-remote bridge. The UID in the header is the only auth — no login step.
The universal flow:  add https://mcp.waveassist.ai/mcp with Authorization: Bearer <UID> → add the skill (the build brain) → say “using waveassist, build an agent that … every Monday 9am” → it designs nodes, writes code, deploys unarmed, runs a live test, and arms the schedule only when green.
End user · Claude Code

Add URL + skill

Remote server via claude mcp add; skill via the plugin.

  1. Add the hosted server
    claude mcp add --transport http \
  waveassist https://mcp.waveassist.ai/mcp \
  --header "Authorization: Bearer <UID>"
  2. Add the skill (build brain)
    /plugin marketplace add WaveAssist/WaveAgent
/plugin install waveassist@waveassist-marketplace
  3. Build it
    using waveassist, build an agent
that emails me my GitHub issues
every weekday at 9am
Auth: your UID is in the header — no login step. (The plugin can also ship the URL so you only set one env var.)

Make it live — host the server (free) + publish the skill

Two things power the above. Host the MCP server (one small container) so the URL exists, and publish the skill (GitHub → Claude Code marketplace; copied for Cursor/generic). The same server already runs over HTTP; auth is the per-request Bearer <UID> header.

1 · Host it (free)
Deploy the container
Scale-to-zero free tiers fit an idle MCP server. Point mcp.waveassist.ai at it. Full CI/CD + the recommended free service in docs/HOSTING.md.
cd mcp
docker build -t waveassist-mcp .
# deploy to your free host; it serves /mcp
2 · Publish the skill
Public GitHub repo
Push WaveAssist/WaveAgent public.
gh repo create WaveAssist/WaveAgent \
  --public --source=. --push
→ enables the Claude Code plugin (skill) + the Cursor/generic skill copy
3 · Harden (before public)
Scoped key vs raw UID
Swap the raw-UID header for a scoped, revocable key (or OAuth, so the plugin can ship a static URL + browser login). Private-beta-fine as-is.

No PyPI needed for the hosted path — the server runs on your host, not on the user's machine. (PyPI/uvx stays as the optional self-host / dev route.) Per-user agent registry is a local file on the host — mount a volume for durability; see docs/HOSTING.md.
