WaveAgent

Build & deploy deterministic, recurring WaveAssist agents from inside Claude Code or Cursor — in plain English.
✓ Live-proven (real email sent) ✓ 28 unit tests ✓ Fresh review: 32 fixes ✓ Beta-ready

1 · What's done

  • A new product at WA/WaveAgent/ — three layers in one repo: a portable SKILL (the build-time brain), a thin MCP server (8 typed tools, zero reasoning), and packaging for a Claude Code plugin + a Cursor mirror.
  • No Composio, no call_tool. Generated agents reach any tool with plain requests + a key you store in WaveAssist; call_llm handles runtime reasoning (no user LLM key).
  • Proven end-to-end on the live API with a ClickUp→weekly-email agent: create → push code → install → test → arm schedule → a real AI-written email delivered.
  • Audited & hardened: a fresh multi-agent review found 32 issues (1 blocker, 8 major, rest minor/nit) — all fixed and re-verified (parity in sync, no secrets leaked, plugin server loads all 8 tools).

2 · How it works

The host coding agent is the brain. Driven by the SKILL, it runs this loop and the MCP tools just talk to WaveAssist:

1 auth (your UID) → 2 gather requirements → 3 design nodes & confirm with you → 4 collect keys (reuses what's available; else shows you how to get the token) → 5 write flat {node}.py + config.yaml → 6 deploy unarmed → 7 live dry-run test (side-effects gated) → 8 fix until green → 9 arm the schedule — never before a green test.

A deployed agent = a GitHub repo of config.yaml + one flat Python file per node, wired only through WaveAssist's key-value store, run on a schedule by WaveAssist's workers.
